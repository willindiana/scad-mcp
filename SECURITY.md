# Security policy

Report vulnerabilities using **Security → Report a vulnerability** in this project's GitHub repository (private vulnerability reporting). Maintainers must enable that feature before public launch. Do not post credentials, exploit details, private paths or logs in public issues.

Only latest released version receives security fixes. Never share API keys in model context. Use owner-only secret files, authenticated encrypted transport, least-privilege runtime mounts and explicit human approval for destructive or physical actions. A license override is not permission to redistribute upstream content.
